# Contos de Mística RPG

Comece pela [criação de personagem](jogador/criacao-de-personagem.md). Você vai escolher uma espécie, distribuir atributos e treinamento, calcular as reservas de Alma e preparar o equipamento para a primeira sessão.

## Durante a sessão

| O que você quer fazer? | Onde consultar |
|---|---|
| Resolver um teste ou conferir os PA de uma reação | [Guia rápido de mesa](jogador/guia-rapido.md) |
| Procurar uma regra de combate, exploração ou descanso | [Índice de regras](regras/README.md) |
| Conferir uma sigla da ficha | [Glossário](jogador/glossario.md) |
| Comparar os traços das 14 espécies | [Origens e espécies](regras/origens/README.md) |

## Organização do repositório

| Pasta | Conteúdo |
|---|---|
| `jogador/` | Criação da ficha, guia rápido e glossário |
| `regras/` | Capítulos completos, agrupados por assunto |
| `design/` | [Pendências](design/pendencias.md), decisões e propostas |
| `planejamento/` | Preparação de sessões, playtests e repasses |
| `site/` | [Portal do manual](site/README.md) |
| `mesa-web/` | [Material de apoio à mesa](mesa-web/README.md) |

Para acompanhar o desenvolvimento, consulte o [estado do projeto](ESTADO-DO-PROJETO.md), as [mudanças](CHANGELOG.md) e as [orientações de colaboração](AGENTS.md).
